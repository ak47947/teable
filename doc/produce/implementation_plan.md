## 1. 实施概述

### 1.1 目标

基于 Teable 开源版实现完整的自动化功能,包括:
- ✅ 触发器系统 (记录创建/更新/字段变更/定时)
- ✅ 条件判断系统 (字段值比较、逻辑组合)
- ✅ 动作执行系统 (更新字段、创建记录、发送通知、Webhook)
- ✅ 可视化编辑器 (基于 React Flow)
- ✅ 执行历史和日志

### 1.2 交付标准

- **功能完整性**: 实现设计文档中定义的所有 P0 和 P1 功能
- **代码质量**: 单元测试覆盖率 > 80%
- **性能指标**: 
  - 工作流执行延迟 < 500ms
  - 支持 100+ 并发工作流
  - 可视化编辑器流畅度 > 60fps
- **用户体验**: 界面直观,操作流畅,错误提示清晰

### 阶段 2: 核心触发器与动作 (Week 4-6)

#### 目标
实现基础触发器和动作,使自动化引擎可以运行简单的工作流。

#### 主要任务

**1. 触发器实现**
- [ ] 记录创建触发器 (`RecordCreatedTrigger`)
  - 监听 `record.created` 事件
  - 提取触发上下文
- [ ] 记录更新触发器 (`RecordUpdatedTrigger`)
  - 监听 `record.updated` 事件
  - 提取变更前后的数据
- [ ] 字段变更触发器 (`FieldChangedTrigger`)
  - 监听 `field.changed` 事件
  - 支持特定字段监听
  - 支持"从A变为B"的条件
- [ ] 定时触发器 (`ScheduleTrigger`)
  - 集成 node-cron
  - 支持 cron 表达式
  - 支持简单的时间选择(每天/每周/每月)
- [ ] 编写触发器单元测试

**2. 条件判断**
- [ ] 实现 ConditionEvaluator
  - 字段值比较
  - 支持操作符: equals, not_equals, contains, greater_than, less_than, is_empty, is_not_empty
  - 支持逻辑运算: AND, OR
- [ ] 实现上下文变量解析
  - `{{trigger.recordId}}`
  - `{{record.fieldName}}`
- [ ] 编写条件判断单元测试

**3. 动作实现**
- [ ] 更新字段动作 (`UpdateFieldAction`)
  - 支持更新单个或多个字段
  - 支持变量替换
- [ ] 创建记录动作 (`CreateRecordAction`)
  - 支持在同表或其他表创建记录
  - 支持字段映射
- [ ] 发送通知动作 (`SendNotificationAction`)
  - 集成现有通知系统
  - 支持 @提到用户
- [ ] 发送 Webhook 动作 (`SendWebhookAction`)
  - 支持 POST/GET 请求
  - 支持自定义 Headers
  - 支持请求体模板
- [ ] 编写动作单元测试

**4. 执行引擎**
- [ ] 实现 ExecutionService
  - 工作流执行调度
  - 上下文构建
  - 条件评估
  - 动作执行
  - 错误处理
  - 重试机制
- [ ] 实现 ExecutionLogger
  - 记录执行日志
  - 记录执行状态
- [ ] 编写执行引擎集成测试

## 3. 技术准备

### 3.1 依赖安装

**后端依赖**:
```bash
# 消息队列
pnpm add bullmq ioredis
pnpm add -D @types/ioredis

# 定时任务
pnpm add node-cron
pnpm add -D @types/node-cron

# 事件系统
pnpm add eventemitter2
pnpm add -D @types/eventemitter2
```

**前端依赖**:
```bash
# 流程图库
pnpm add reactflow

# 状态管理
pnpm add zustand

# 表单
pnpm add react-hook-form @hookform/resolvers zod

# 图表
pnpm add recharts
```

### 3.2 环境配置

**Redis** (用于消息队列):
```bash
# Docker 方式
docker run -d --name redis -p 6379:6379 redis:latest

# 或在 docker-compose.yml 中添加
services:
  redis:
    image: redis:latest
    ports:
      - "6379:6379"
```

**环境变量**:
```env
# Redis 配置
REDIS_HOST=localhost
REDIS_PORT=6379
REDIS_PASSWORD=

# 自动化配置
AUTOMATION_ENABLED=true
AUTOMATION_MAX_EXECUTIONS_PER_HOUR=100
AUTOMATION_RETRY_ENABLED=true
AUTOMATION_MAX_RETRIES=3
```
