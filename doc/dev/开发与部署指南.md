## 开发环境搭建

### 系统要求

- **操作系统**: macOS, Linux, Windows (WSL2)
- **Node.js**: >= 20.0.0
- **pnpm**: >= 9.13.0
- **数据库**: PostgreSQL 15+ (生产) 或 SQLite (开发)
- **Redis**: 7.2+ (可选，用于缓存)
- **内存**: 至少 8GB RAM
- **磁盘**: 至少 10GB 可用空间

### 快速开始

#### 1. 克隆项目

```bash
git clone https://github.com/teableio/teable.git
cd teable
```

#### 2. 安装依赖

```bash
# 启用 pnpm
corepack enable

# 安装所有依赖
pnpm install
```

#### 3. 选择数据库模式

**选项 A: 使用 SQLite (推荐用于开发)**

```bash
make switch-db-mode
# 选择 1 或输入 sqlite
```

优点：
- 无需额外安装数据库
- 快速启动
- 适合本地开发

缺点：
- 不支持并发写入
- 功能有限

**选项 B: 使用 PostgreSQL (推荐用于生产)**

```bash
# 启动 PostgreSQL (使用 Docker)
make docker.up teable-postgres
make docker.await teable-postgres

# 切换到 PostgreSQL 模式
make switch-db-mode
# 选择 2 或输入 postgres
```

#### 4. 启动开发服务器

```bash
cd apps/nestjs-backend
pnpm dev
```

这将自动启动：
- 后端服务 (NestJS)
- 前端服务 (Next.js)
- 热重载

访问 http://localhost:3000

#### 5. 启动插件开发服务器（可选）

```bash
# 构建依赖包
pnpm build:packages

# 启动插件服务器
cd plugins
pnpm dev
```

访问 http://localhost:3002

### 4. 添加 API 端点

#### 步骤 1: 定义 DTO

```typescript
// apps/nestjs-backend/src/features/my-feature/dto/create-my-feature.dto.ts
import { IsString, IsOptional } from 'class-validator';

export class CreateMyFeatureDto {
  @IsString()
  name: string;
  
  @IsOptional()
  @IsString()
  description?: string;
}
```

#### 步骤 2: 创建 Service

```typescript
// apps/nestjs-backend/src/features/my-feature/my-feature.service.ts
import { Injectable } from '@nestjs/common';
import { PrismaService } from '@teable/db-main-prisma';

@Injectable()
export class MyFeatureService {
  constructor(private readonly prisma: PrismaService) {}
  
  async create(dto: CreateMyFeatureDto) {
    return this.prisma.myFeature.create({
      data: dto,
    });
  }
}
```

#### 步骤 3: 创建 Controller

```typescript
// apps/nestjs-backend/src/features/my-feature/my-feature.controller.ts
import { Controller, Post, Body } from '@nestjs/common';
import { ApiTags, ApiOperation } from '@nestjs/swagger';
import { MyFeatureService } from './my-feature.service';
import { CreateMyFeatureDto } from './dto/create-my-feature.dto';

@ApiTags('my-feature')
@Controller('api/my-feature')
export class MyFeatureController {
  constructor(private readonly service: MyFeatureService) {}
  
  @Post()
  @ApiOperation({ summary: 'Create my feature' })
  create(@Body() dto: CreateMyFeatureDto) {
    return this.service.create(dto);
  }
}
```

#### 步骤 4: 创建 Module

```typescript
// apps/nestjs-backend/src/features/my-feature/my-feature.module.ts
import { Module } from '@nestjs/common';
import { MyFeatureController } from './my-feature.controller';
import { MyFeatureService } from './my-feature.service';

@Module({
  controllers: [MyFeatureController],
  providers: [MyFeatureService],
  exports: [MyFeatureService],
})
export class MyFeatureModule {}
```

#### 步骤 5: 注册到 AppModule

```typescript
// apps/nestjs-backend/src/app.module.ts
import { MyFeatureModule } from './features/my-feature/my-feature.module';

@Module({
  imports: [
    // ... 其他模块
    MyFeatureModule,
  ],
})
export class AppModule {}
```

## 部署方案

### 方案 1: Docker Compose (单机部署)

**适用场景**: 小型团队，单服务器部署

#### 步骤 1: 准备环境

```bash
# 克隆项目
git clone https://github.com/teableio/teable.git
cd teable/dockers/examples/standalone

# 配置环境变量
cp .env.example .env
vim .env
```

#### 步骤 2: 配置 .env

```env
# 时区
TIMEZONE=Asia/Shanghai

# 数据库配置
POSTGRES_DB=teable
POSTGRES_USER=teable
POSTGRES_PASSWORD=your_secure_password

# Redis 配置
REDIS_PASSWORD=your_redis_password

# 应用配置
PUBLIC_ORIGIN=https://your-domain.com
BACKEND_JWT_SECRET=your_jwt_secret

# 存储配置（可选）
STORAGE_TYPE=minio
MINIO_ACCESS_KEY=minioadmin
MINIO_SECRET_KEY=minioadmin
```

#### 步骤 3: 启动服务

```bash
docker-compose up -d
```

#### 步骤 4: 检查状态

```bash
docker-compose ps
docker-compose logs -f teable
```

访问 http://your-server:3000

### 方案 2: Kubernetes 部署

**适用场景**: 中大型团队，需要高可用

#### 步骤 1: 准备 Kubernetes 集群

```bash
# 确保 kubectl 已配置
kubectl cluster-info
```

#### 步骤 2: 创建命名空间

```bash
kubectl create namespace teable
```

#### 步骤 3: 创建配置

```yaml
# k8s/configmap.yaml
apiVersion: v1
kind: ConfigMap
metadata:
  name: teable-config
  namespace: teable
data:
  POSTGRES_HOST: teable-postgres
  POSTGRES_PORT: "5432"
  POSTGRES_DB: teable
  REDIS_HOST: teable-redis
  REDIS_PORT: "6379"
```

#### 步骤 4: 创建 Secret

```bash
kubectl create secret generic teable-secrets \
  --from-literal=POSTGRES_PASSWORD=your_password \
  --from-literal=REDIS_PASSWORD=your_redis_password \
  --from-literal=JWT_SECRET=your_jwt_secret \
  -n teable
```

#### 步骤 5: 部署数据库

```yaml
# k8s/postgres.yaml
apiVersion: apps/v1
kind: StatefulSet
metadata:
  name: teable-postgres
  namespace: teable
spec:
  serviceName: teable-postgres
  replicas: 1
  selector:
    matchLabels:
      app: teable-postgres
  template:
    metadata:
      labels:
        app: teable-postgres
    spec:
      containers:
      - name: postgres
        image: postgres:15.4
        ports:
        - containerPort: 5432
        env:
        - name: POSTGRES_DB
          valueFrom:
            configMapKeyRef:
              name: teable-config
              key: POSTGRES_DB
        - name: POSTGRES_PASSWORD
          valueFrom:
            secretKeyRef:
              name: teable-secrets
              key: POSTGRES_PASSWORD
        volumeMounts:
        - name: data
          mountPath: /var/lib/postgresql/data
  volumeClaimTemplates:
  - metadata:
      name: data
    spec:
      accessModes: ["ReadWriteOnce"]
      resources:
        requests:
          storage: 20Gi
```

#### 步骤 6: 部署应用

```yaml
# k8s/teable.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: teable
  namespace: teable
spec:
  replicas: 3
  selector:
    matchLabels:
      app: teable
  template:
    metadata:
      labels:
        app: teable
    spec:
      containers:
      - name: teable
        image: ghcr.io/teableio/teable:latest
        ports:
        - containerPort: 3000
        envFrom:
        - configMapRef:
            name: teable-config
        - secretRef:
            name: teable-secrets
        resources:
          requests:
            memory: "512Mi"

          limits:
            memory: "2Gi"

---
apiVersion: v1
kind: Service
metadata:
  name: teable
  namespace: teable
spec:
  selector:
    app: teable
  ports:
  - port: 80
    targetPort: 3000
  type: LoadBalancer
```

```bash
kubectl apply -f k8s/
```

## 故障排查

### 问题 1: 数据库连接失败

**症状**:
```
Error: P1001: Can't reach database server
```

**解决方案**:

1. 检查数据库是否运行：
```bash
# Docker
docker ps | grep postgres

# 本地 PostgreSQL
pg_isready -h localhost -p 5432
```

2. 检查连接字符串：
```bash
# 查看环境变量
echo $PRISMA_DATABASE_URL

# 测试连接
psql postgresql://teable:teable@localhost:5432/teable
```

3. 检查防火墙：
```bash
# 检查端口是否开放
telnet localhost 5432
```

---

### 问题 2: 前端无法连接后端

**症状**:
```
Network Error: Failed to fetch
```

**解决方案**:

1. 检查后端是否运行：
```bash
curl http://localhost:3000/api/health
```

2. 检查环境变量：
```bash
# apps/nextjs-app/.env.development.local
NEXT_PUBLIC_API_URL=http://localhost:3000/api
```

3. 检查 CORS 配置：
```typescript
// apps/nestjs-backend/src/main.ts
app.enableCors({
  origin: process.env.PUBLIC_ORIGIN || 'http://localhost:3000',
  credentials: true,
});
```

---

### 问题 3: 构建失败

**症状**:
```
Error: Cannot find module '@teable/core'
```

**解决方案**:

1. 清理并重新安装：
```bash
pnpm g:clean
rm -rf node_modules
pnpm install
```

2. 构建依赖包：
```bash
pnpm build:packages
```

3. 检查 TypeScript 配置：
```bash
pnpm g:typecheck
```

---

### 问题 4: 迁移失败

**症状**:
```
Error: Migration failed to apply
```

**解决方案**:

1. 检查迁移状态：
```bash
cd packages/db-main-prisma
pnpm prisma migrate status
```

2. 重置数据库（开发环境）：
```bash
pnpm prisma migrate reset
```

3. 手动修复迁移：
```bash
# 查看失败的迁移
cat prisma/migrations/[migration-name]/migration.sql

# 手动执行 SQL
psql -U teable -d teable -f prisma/migrations/[migration-name]/migration.sql
```

## 性能优化

### 1. 数据库优化

#### 添加索引

```sql
-- 为常用查询添加索引
CREATE INDEX idx_record_table_id ON "Record"("tableId");
CREATE INDEX idx_field_table_id ON "Field"("tableId");
CREATE INDEX idx_view_table_id ON "View"("tableId");

-- 复合索引
CREATE INDEX idx_record_table_created ON "Record"("tableId", "createdTime");
```

#### 优化查询

```typescript
// 使用 select 减少数据传输
const records = await prisma.record.findMany({
  where: { tableId },
  select: {
    id: true,
    fields: true,
    // 只选择需要的字段
  },
});

// 使用 include 减少查询次数
const table = await prisma.table.findUnique({
  where: { id: tableId },
  include: {
    fields: true,
    views: true,
  },
});
```

### 2. 缓存优化

#### Redis 缓存

```typescript
// apps/nestjs-backend/src/core/cache/cache.service.ts
@Injectable()
export class CacheService {
  constructor(private readonly redis: Redis) {}
  
  async get<T>(key: string): Promise<T | null> {
    const value = await this.redis.get(key);
    return value ? JSON.parse(value) : null;
  }
  
  async set(key: string, value: any, ttl = 3600): Promise<void> {
    await this.redis.setex(key, ttl, JSON.stringify(value));
  }
  
  async del(key: string): Promise<void> {
    await this.redis.del(key);
  }
}
```

#### 使用缓存

```typescript
// 缓存表数据
async getTable(tableId: string) {
  const cacheKey = `table:${tableId}`;
  
  // 尝试从缓存获取
  let table = await this.cache.get(cacheKey);
  
  if (!table) {
    // 从数据库查询
    table = await this.prisma.table.findUnique({
      where: { id: tableId },
    });
    
    // 写入缓存
    await this.cache.set(cacheKey, table, 3600);
  }
  
  return table;
}
```
