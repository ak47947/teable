## 项目概览

Teable 是一个基于 **Monorepo** 架构的项目，使用 **pnpm workspace** 管理多个包和应用。

### 技术架构

```
┌─────────────────────────────────────────────────────────┐
│                     用户界面层                            │
│              (Next.js App - Port 3000)                  │
└─────────────────────────────────────────────────────────┘
                           │
                           ↓
┌─────────────────────────────────────────────────────────┐
│                     API 网关层                           │
│              (NestJS Backend - Port 3000)               │
└─────────────────────────────────────────────────────────┘
                           │
        ┌──────────────────┼──────────────────┐
        ↓                  ↓                  ↓
┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│  PostgreSQL  │  │    Redis     │  │    MinIO     │
│   (数据库)    │  │   (缓存)     │  │  (文件存储)   │
└──────────────┘  └──────────────┘  └──────────────┘
```

### 许可证分布

- **AGPL 3.0**: `apps/`, `plugins/` - 应用程序代码
- **MIT**: `packages/` - 可复用的库和工具

#### 核心功能模块

1. **Grid View (表格视图)**
   - 使用 `@glideapps/glide-data-grid` 实现高性能表格
   - 支持虚拟滚动，可处理百万行数据
   - 实时协作编辑

2. **Kanban View (看板视图)**
   - 使用 `@hello-pangea/dnd` 实现拖拽
   - 支持分组和过滤

3. **Calendar View (日历视图)**
   - 使用 `@fullcalendar/react`
   - 支持日、周、月视图

4. **Form View (表单视图)**
   - 使用 `react-hook-form` + `zod` 验证
   - 支持多种字段类型

5. **Plugin System (插件系统)**
   - 使用 iframe 隔离插件
   - 通过 `penpal` 实现跨窗口通信

#### 核心功能模块

1. **Base (数据库)**
   - 数据库的创建、删除、权限管理
   - 支持多租户

2. **Table (表)**
   - 表的 CRUD 操作
   - 表结构管理

3. **Field (字段)**
   - 20+ 种字段类型
   - 字段类型转换
   - 字段验证规则

4. **Record (记录)**
   - 记录的 CRUD 操作
   - 批量操作
   - 记录历史

5. **View (视图)**
   - 视图配置管理
   - 过滤、排序、分组

6. **Collaboration (协作)**
   - 基于 ShareDB 的 OT (Operational Transformation)
   - WebSocket 实时通信
   - 冲突解决

7. **Storage (存储)**
   - 支持 MinIO / S3
   - 文件上传、下载
   - 图片处理 (Sharp)

**核心表结构**:

```prisma
// 主要数据模型
model Space {
  id        String   @id
  name      String
  bases     Base[]
  users     SpaceUser[]
}

model Base {
  id        String   @id
  name      String
  spaceId   String
  space     Space    @relation(fields: [spaceId])
  tables    Table[]
}

model Table {
  id        String   @id
  name      String
  baseId    String
  base      Base     @relation(fields: [baseId])
  fields    Field[]
  records   Record[]
  views     View[]
}

model Field {
  id        String   @id
  name      String
  type      String   // 字段类型
  options   Json?    // 字段配置
  tableId   String
  table     Table    @relation(fields: [tableId])
}

model Record {
  id        String   @id
  fields    Json     // 记录数据
  tableId   String
  table     Table    @relation(fields: [tableId])
}

model View {
  id        String   @id
  name      String
  type      String   // grid, kanban, calendar, etc.
  filter    Json?
  sort      Json?
  group     Json?
  tableId   String
  table     Table    @relation(fields: [tableId])
}
```

## 数据流向

### 1. 用户操作流程

```
用户操作 (浏览器)
    ↓
Next.js 前端 (React 组件)
    ↓
TanStack Query (数据请求)
    ↓
API 客户端 (Axios)
    ↓
NestJS 后端 (Controller)
    ↓
Service 层 (业务逻辑)
    ↓
Prisma ORM
```

## 总结

Teable 的项目结构遵循以下原则：

1. **模块化**: 功能按模块划分，职责清晰
2. **可复用**: 共享代码抽取到 packages
3. **类型安全**: 全面使用 TypeScript
4. **可测试**: 单元测试和 E2E 测试覆盖
5. **可扩展**: 插件系统支持功能扩展
6. **可部署**: Docker 化，支持多种部署方式

理解这个结构将帮助您更好地开发和维护 Teable 项目。
